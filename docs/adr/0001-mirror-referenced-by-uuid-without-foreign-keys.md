# Mirror rows are referenced by archive uuid with no foreign keys; re-import wipes and replaces

The Mirror (Song, Artist, Album, Track, Version, Performance) is a read-only copy of the Tuvan Lyrics Archive, refreshed by importing a newer backup. Local tables (video, chapter, artist, the Links and song suggestions) keep the archive's uuids as plain TEXT columns with no foreign key to any `mirror_*` table, and an import is one transaction that deletes every `mirror_*` row and inserts the new set, leaving local tables untouched. The alternatives were row-by-row upserts with deletes (fragile against archive-side renames and deletions) and a second database file swapped in (two files to keep consistent). Consequence: after an import a local row may point at a uuid that no longer exists; it stays, renders as "unknown song" or "unknown artist", and is counted in the import record rather than nulled out. Decided in [issue #13](https://github.com/IncoherentThoughts/TuvaVideos/issues/13).
